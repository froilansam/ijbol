# Finishing Touches

Cheap, high-leverage moves that take a design from "fine" to "designed" — none require graphic-design talent.

## Supercharge the defaults

Restyle elements that already exist instead of adding new ones:

- **Bulleted lists** → icon bullets: checkmarks/arrows generically, or content-specific icons (padlock for security features).
- **Testimonials** → promote the quotation marks into oversized, colored visual elements.
- **Links** → heavier weight + color, or a thick colorful underline that slightly overlaps the text.
- **Checkboxes/radios** → custom-styled with a brand color for the selected state. Browser defaults read as "unfinished"; this alone signals polish.

## Accent borders

A colored rectangle is the cheapest "designed" signal available. Locations:

- Across the top of a card
- Under/beside the active nav item
- Down the side of an alert
- A short underline accent beneath a headline
- Full-width across the very top of the layout

## Decorate backgrounds

Break monotony without redesigning:

- **Shift the background color** of a panel or page section. Gradients work — keep the two hues within ~30° of each other.
- **Repeating pattern** at low contrast (e.g. Hero Patterns) — full-bleed, or along a single edge.
- **Single placed graphic**: a geometric shape, a fragment of a pattern, a simplified map. Always low contrast so content stays readable.

## Don't overlook empty states

Empty state = the user's *first* encounter with a feature. It's a priority, not an afterthought:

- Lead with an image/illustration, emphasize the call-to-action.
- **Hide ancillary chrome** (tabs, filters, sort controls) that does nothing until content exists.
- Never ship the sad grey "No items found" default.

## Use fewer borders

Borders multiply quickly and make UIs busy. Before adding one, try:

1. **Box shadow** — outlines an element more softly (best when the element's color differs from the background).
2. **Different background colors** on adjacent elements — usually enough by itself; if a border coexists with a bg-color change, try deleting the border.
3. **More spacing** — separation by literal separation, zero added UI.

## Think outside the box

Components don't owe their stereotypes anything:

- **Dropdowns** can have sections, columns, supporting text, colorful icons — it's just a floating box.
- **Tables** can merge related columns into one cell with internal hierarchy (name over title), include avatars/images, use colored badges.
- **Radio groups** that matter can become **selectable cards**.

## Leveling up (ongoing habit)

- In designs you admire, hunt for **decisions you wouldn't have made** (inverted datepicker colors, a button inside an input, two-tone headlines) — that's where new tools come from.
- **Rebuild favorite interfaces from scratch without inspecting** — the deltas between your version and theirs surface the non-obvious tricks (tighter heading line-height, all-caps letter-spacing, layered shadows).
